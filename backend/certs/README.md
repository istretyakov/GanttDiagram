Положите сюда корневой сертификат внутреннего центра сертификации (`*.crt`, формат PEM),
если Jira работает по HTTPS с сертификатом компании. При сборке Docker-образа API он будет
добавлен в доверенные (`update-ca-certificates`).

При локальном запуске без Docker добавьте сертификат в хранилище доверенных корневых
сертификатов системы. Флаг `Jira:AllowInvalidCertificates=true` отключает проверку — только для разработки.
